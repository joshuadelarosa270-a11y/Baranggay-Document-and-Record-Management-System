Paano kumuha ng dokumento

  1. Mag-login

    Magpatala muna kung wala ka pang account. Hihintayin ang pag-apruba ng Kalihim.

  2. Magsumite ng request

    Piliin ang dokumento at ilagay ang layunin at valid ID.

  3. I-track ang request

    Gamitin ang reference number at apelyido habang sinusuri ng Kalihim.

  4. Kunin sa barangay hall

    Dalhin ang valid ID at reference number kapag handa na ang dokumento.
